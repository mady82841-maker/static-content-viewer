# Static Content Viewer

A simple and elegant web page that displays static content using PHP, HTML, and CSS.

## Features

- Clean and responsive design
- Static text content provided by PHP
- Landscape image with a caption
- Separation of content data from the presentation layer
- Responsive layout for different screen sizes

## Technologies Used

- PHP
- HTML5
- CSS3
- XAMPP (Apache)

## Project Structure

static-content-viewer/
├── index.php
├── content.php
├── style.css
└── README.md
## How to Run

1. Install and start XAMPP.
2. Place the project folder inside D:/xampp/htdocs/.
3. Start Apache from the XAMPP Control Panel.
4. Open the following URL in your browser:

   http://localhost/static-content-viewer/

## Notes

The project displays predefined static content. No database or user interaction is required.
